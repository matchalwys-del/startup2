# Chevron - Custom New Tab Extension (v2.0 Upgrade)

## Features
- **Anti-FOUC (Flash of Unstyled Content):** Instant dark/light mode load without screen blinking.
- **Dual Storage Sync:** Syncs options via `chrome.storage.sync` with local fallback.
- **Keyboard Shortcut:** Press `/` or `Ctrl + K` to jump instantly to search bar.
- **Backup & Restore:** Export settings into JSON anytime.

## How to Install (Developer Mode)
1. Extract `chevron-v2-upgrade.zip`.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** toggle at top right.
4. Click **Load unpacked** and select this directory.
5. Open a new tab!
